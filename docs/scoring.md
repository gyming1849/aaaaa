# 离线评分标准 v2

本文档说明“食迹 NutriLog”如何在**不调用 AI** 的情况下给每天、每周、每月打分。AI（Claude）只负责把“吃了什么”“做了什么运动”拆成营养素、食物组、风险标记和运动 MET；**所有评分都由服务器上的确定性代码完成**（`server/src/scoring/`），结果可复现、可追溯到出处。

**v2 的原则：只使用已发表、经同行评议的评分体系，不自定权重。** v1 中“膳食质量 35% + 营养素 25% + 限量 25% + 能量 15% − 风险物扣分”的权重是本系统自己定的，没有权威依据，v2 已经全部移除。现在每个分数都能对应到一篇论文或一份官方文件：

| 在哪里看到 | 分数 | 满分 | 出处 |
|---|---|---|---|
| **每天的总分** | 膳食质量 HEI-2020 | 0–100 | USDA / NCI 健康饮食指数，美国人平均 58 分 |
| 每天（附） | 微量营养素充足 MAR | 0–100 | 平均充足比（Arimond 2010，FAO MDD-W 的验证基础） |
| 今日页（近 7 天滚动） | 心血管健康 Life's Essential 8 | 0–100 | 美国心脏协会 AHA 2022 |
| 今日页（近 7 天滚动） | 防癌建议 WCRF/AICR | 0–6 | 2018 WCRF/AICR 标准化评分（Shams-White 2019） |
| **每周 / 每月的总分** | Life's Essential 8 | 0–100 | 同上，按整个周期的数据计算 |
| 周报 / 月报（附） | HEI-2020（按周期总摄入）、HEI 日均、MAR 日均、WCRF | — | 同上 |

其余内容（钠、添加糖、饱和脂肪、酒精、每种营养素是否达到 RDA、能量是否平衡、IARC 致癌物）都只标“达标 / 偏离 / 不达标”并写明超出或差多少，**不再折算成分数**。

网站“标准库”页面展示同样的内容，并按你的个人档案给出具体数值。

## 2. 个性化目标（与年龄、性别、身高、体重挂钩）

| 项目 | 计算方式 |
|---|---|
| 人群分组 | 按年龄与性别映射到 DRI 的 20 个人群；女性可选孕期 / 哺乳期 |
| 基础代谢 BMR | Mifflin-St Jeor：10W + 6.25H − 5A + 5（男）/ −161（女） |
| 能量需求 EER | 19 岁及以上：NASEM 2023 方程（按久坐 / 轻度 / 活跃 / 非常活跃四档）；未成年人：BMR × PAL 近似；孕期 +340、哺乳期 +330 kcal |
| 能量目标 | EER ± 目标调整（减重：每周速度 × 7700 ÷ 7；增重：≤ +500），不低于 BMR 与 1200（女）/ 1500（男）kcal；达到目标体重后自动转为维持；孕期 / 哺乳期不做减重 |
| 蛋白质 | RDA = max(人群 RDA, g/kg × 参考体重)；成人 0.8 g/kg，孕期 1.1，哺乳期 1.3；DGA 2025–2030 理想区间 1.2–1.6 g/kg。BMI ≥ 30 时参考体重 = 理想体重 + 0.4 ×（实际 − 理想） |
| 膳食纤维 | 14 g / 1000 kcal × 个人能量目标 |
| 钠 | 上限 = CDRR（14 岁以上 2300 mg）；高血压或选择 AHA 模式时上限 1500 mg；成人理想 1500 mg |
| 添加糖 | 上限 = max(DGA 2020 的 10% 能量, AHA 值)；糖尿病时收紧到 AHA；理想 = AHA（女 25 g / 男 36 g / 儿童 25 g）；每餐 ≤ 10 g（DGA 2025–2030） |
| 饱和脂肪 | 上限 10% 能量；理想 8%（HEI 满分线），高 LDL 时 6%（AHA） |
| 反式脂肪 | 上限 = 1% 能量（WHO） |
| 酒精 | 理想 0；上限男 28 g、女 14 g（DGA 2020–2025）；孕期 / 哺乳期 / 未满 21 岁为 0 |
| 咖啡因 | 成人 400 mg；孕期 / 哺乳期 200 mg；未成年人 2.5 mg/kg |
| 阿斯巴甜 | ADI 40 mg/kg 体重 |
| 超加工食品 | NOVA 4 类供能比：理想 ≤ 20%，上限 50%（DGA 2025–2030 要求限制但未给数值，阈值为本系统设定，只标状态） |

每天的计算都使用**当天或之前最近一次称重**的体重，所以体重变化后目标会自动跟着变。

## 3. 每日评分

### 3.1 总分：HEI-2020（0–100）

每天的总分就是当天饮食的 HEI-2020 总分。HEI 由 USDA 与美国国家癌症研究所制定，用来衡量饮食与美国膳食指南的符合程度；13 个组分的分值由 USDA 规定，本系统没有做任何调整。各组分按**每 1000 kcal 的密度**在“零分标准”和“满分标准”之间线性计分：

| 组分 | 满分 | 满分标准（每 1000 kcal） | 零分标准 |
|---|---|---|---|
| 水果总量 | 5 | ≥ 0.8 杯当量 | 0 |
| 完整水果 | 5 | ≥ 0.4 杯当量 | 0 |
| 蔬菜总量 | 5 | ≥ 1.1 杯当量 | 0 |
| 深绿色蔬菜与豆类 | 5 | ≥ 0.2 杯当量 | 0 |
| 全谷物 | 10 | ≥ 1.5 盎司当量 | 0 |
| 奶制品 | 10 | ≥ 1.3 杯当量 | 0 |
| 蛋白质食物 | 5 | ≥ 2.5 盎司当量 | 0 |
| 海产与植物蛋白 | 5 | ≥ 0.8 盎司当量 | 0 |
| 脂肪酸比例 (PUFA+MUFA)/SFA | 10 | ≥ 2.5 | ≤ 1.2 |
| 精制谷物 | 10 | ≤ 1.8 盎司当量 | ≥ 4.3 |
| 钠 | 10 | ≤ 1.1 g | ≥ 2.0 g |
| 添加糖 | 10 | ≤ 6.5% 能量 | ≥ 26% |
| 饱和脂肪 | 10 | ≤ 8% 能量 | ≥ 16% |

豆类同时计入“蔬菜总量”“深绿色蔬菜与豆类”“蛋白质食物”“海产与植物蛋白”（1 杯豆类 = 4 盎司当量蛋白质）。

页面会逐项写明“钠组分扣 x 分”。**例：** 一天吃 2000 kcal、钠 4000 mg，即 2.0 g/1000 kcal，钠组分得 0 分，扣满 10 分；同一天如果钠 2200 mg（1.1 g/1000 kcal），钠组分满分。

参照：美国 2 岁以上人群 HEI-2020 平均 58 分（NHANES 2017–2018）。页面和趋势图都画出这条参考线。

> HEI 原本用于评估人群或个人较长时间的饮食。单日 HEI 会随当天吃了什么大幅波动，所以趋势图同时画 7 日均线，周报 / 月报还会按**整个周期的总摄入**再算一次 HEI（更稳定）。

### 3.2 微量营养素充足 MAR（0–100，附）

HEI 不评估维生素和矿物质，所以另外给出 MAR（Mean Adequacy Ratio，平均充足比）：

```
NAR（每种营养素）= min(摄入 ÷ 个人 RDA, 1)
MAR = 11 种 NAR 的算术平均 × 100
```

11 种微量营养素沿用 Arimond 等 2010 年多国验证研究（FAO“女性最低膳食多样性 MDD-W”指标的依据）：维生素 A、维生素 B1、维生素 B2、烟酸、维生素 B6、叶酸、维生素 B12、维生素 C、钙、铁、锌。等权，封顶 100%，超过 RDA 不加分。

### 3.3 其余检查项（只标状态）

以下各项在“今日”页的明细表里逐项列出，只显示状态和差距，不计入任何分数：

| 类别 | 项目 | 状态规则 |
|---|---|---|
| 营养素 | 其余所有有 RDA / AI 的营养素（蛋白质、纤维、钾、维生素 D、镁、胆碱、水分等） | ≥ 100% 达标；70–100% 偏离；< 70% 不达标 |
| 限量 | 钠、添加糖、饱和脂肪供能比、反式脂肪、酒精、咖啡因、超加工食品供能比 | ≤ 理想值 达标；理想值 ~ 上限 达标（未到理想）；> 上限 不达标，并写明超出多少 |
| 限量 | 每餐添加糖 ≤ 10 g（DGA 2025–2030） | 全部餐次满足为达标，否则写明哪一餐超过 |
| 限量 | 蛋白质 / 碳水 / 脂肪供能比是否在 AMDR 内；超过 UL 的营养素（只对 UL 适用于总摄入的营养素） | 超出即不达标 |
| 提示 | 膳食胆固醇 | 现行 DGA 没有数值上限，只提示 |
| 能量 | 摄入 vs 今日目标 | 偏差 ≤ 10% 达标；≤ 25% 偏离；> 25% 不达标 |

### 3.4 致癌物与风险物（只警示）

AI 在拆解食物时会标记风险物并估算剂量，服务器按 IARC 分级给出警示：

| 项目 | IARC | 剂量来源 |
|---|---|---|
| 加工肉（培根、火腿、香肠、腊肉…） | 1 | 加工肉克数 |
| 酒精饮料 | 1 | 纯酒精克数 |
| 中式咸鱼、槟榔、黄曲霉毒素风险（发霉坚果谷物、土榨花生油）、羊栖菜（无机砷） | 1 | AI 标记 |
| 红肉 | 2A | 红肉熟重（每天 < 72 g 时不进入“今日要点”，约等于 WCRF 每周 500 g） |
| 高温烧烤 / 焦糊肉类、烟熏食品、丙烯酰胺（油炸 / 烘烤淀粉）、过烫饮品（> 65 °C） | 2A | AI 标记 |
| 传统腌菜、蕨菜 | 2B | AI 标记 |
| 阿斯巴甜 | 2B | AI 标记（mg），只在超过体重对应的 ADI 时警示 |
| 高汞鱼 | — | AI 标记（FDA/EPA 建议避免的品种） |

**为什么不扣分：** IARC 分级表示“致癌证据有多充分”，而不是“危害有多大”。加工肉与吸烟同属 1 类，意味着证据同样确凿，而不是危害同样大。没有任何权威机构发布过把这些分级换算成饮食分数的方法，所以 v2 只按剂量给出警示。其中**加工肉、红肉、酒精、含糖饮料**在 WCRF/AICR 防癌评分（第 5 节）中按其公开规则计分。

“今日要点”列表把风险警示、超标项和 HEI 扣分最多的组分放在一起，按严重程度排序（IARC 1 类 > 2A 类 > 其他风险物 > 超过上限的限量 > HEI 扣分 > 明显不足的营养素）。这个排序只决定显示顺序，不影响任何分数。

## 4. 心血管健康：AHA Life's Essential 8（0–100）

LE8 是美国心脏协会 2022 年发布的心血管健康评分，8 项各 0–100 分：

| 指标 | 计分（AHA 原表） | 本系统的数据来源 |
|---|---|---|
| 饮食 | MEPA 16 题：15–16 → 100；12–14 → 80；8–11 → 50；4–7 → 25；0–3 → 0 | 由饮食记录自动推算（见 4.1），需要 ≥ 3 天记录 |
| 身体活动（分钟/周） | ≥ 150 → 100；120–149 → 90；90–119 → 80；60–89 → 60；30–59 → 40；1–29 → 20；0 → 0 | 运动记录（MET ≥ 3 为中等，MET ≥ 6 为高强度，高强度 1 分钟按 2 分钟计）与手表“锻炼分钟”逐日取较大值，折算成每周 |
| 尼古丁暴露 | 从不吸烟 100；戒烟 ≥ 5 年 75；戒烟 1–5 年 50；戒烟 < 1 年或使用电子烟 25；吸烟 0；家中有人室内吸烟 −20 | 个人档案 |
| 睡眠（小时/晚） | 7–< 9 → 100；9–< 10 → 90；6–< 7 → 70；5–< 6 或 ≥ 10 → 40；4–< 5 → 20；< 4 → 0 | 手动填写、AI 识别截图或苹果健康同步的平均睡眠 |
| BMI | < 25 → 100；25–29.9 → 70；30–34.9 → 30；35–39.9 → 15；≥ 40 → 0 | 最近一次称重 + 身高 |
| 血脂：非 HDL 胆固醇（mg/dL） | < 130 → 100；130–159 → 60；160–189 → 40；190–219 → 20；≥ 220 → 0；服降脂药 −20 | 最近一次体检：总胆固醇 − HDL（可填 mmol/L，自动换算） |
| 血糖 | 无糖尿病：空腹 < 100 且 HbA1c < 5.7 → 100；空腹 100–125 或 HbA1c 5.7–6.4 → 60。糖尿病：HbA1c < 7 → 40；7–7.9 → 30；8–8.9 → 20；9–9.9 → 10；≥ 10 → 0 | 最近一次体检；未标记糖尿病但数值达到诊断水平时按糖尿病档计分，并提示就医确认 |
| 血压（mmHg） | < 120/< 80 → 100；120–129/< 80 → 75；130–139 或 80–89 → 50；140–159 或 90–99 → 25；≥ 160 或 ≥ 100 → 0；服降压药 −20 | 近 90 天最近 3 次测量的平均值 |

```
LE8 总分 = 8 项的等权平均
分级：80–100 高；50–79 中；0–49 低
```

缺少某些指标（例如没有体检数据）时，按 LE8 补充材料 Appendix 2 的做法，对已有指标取平均（分母只算已有指标），页面始终显示“x/8 项”并写明缺哪些数据、怎么补。8 项齐全时与官方定义完全一致。

今日页显示**近 7 天**的滚动 LE8；周报 / 月报的总分是**整个周期**的 LE8。

### 4.1 MEPA 饮食问卷

MEPA（Mediterranean Eating Pattern for Americans）是 LE8 指定的个人饮食评分工具，16 题，每满足一题得 1 分。本系统不让用户填问卷，而是用饮食记录里的食物组数量换算成问卷的“份”：

| 题目 | 满足条件（问卷原文） | 份量换算 |
|---|---|---|
| 橄榄油 | > 2 份/天 | 1 份 = 1 汤匙 ≈ 13.5 g |
| 绿叶蔬菜 | > 7 份/周 | 1 份 = 1 杯生 / ½ 杯熟 ≈ 0.5 杯当量 |
| 其他蔬菜 | > 2 份/天 | 1 份 = ½ 杯 |
| 浆果 | > 2 份/周 | 1 份 = ½ 杯 |
| 其他水果 | > 1 份/天 | 1 份 = ½ 杯 |
| 红肉、汉堡、培根、香肠 | < 3 份/周 | 1 份 = 3 盎司 ≈ 85 g（红肉 + 加工肉） |
| 鱼和贝类 | > 1 份/周 | 1 份 = 3 盎司 |
| 鸡肉 | < 5 份/周 | 1 份 = 3 盎司 |
| 全脂奶酪 / 奶油奶酪 | < 4 份/周 | 1 份 = 1 盎司 ≈ 28 g |
| 黄油 / 奶油 | < 5 份/周 | 1 份 = 1 汤匙 ≈ 14 g |
| 豆类 | > 3 份/周 | 1 份 = ½ 杯 |
| 全谷物 | > 3 份/天 | 1 份 = 1 盎司当量 |
| 商业甜点、糖果、糕点 | < 4 份/周 | AI 估算份数 |
| 坚果 | > 4 份/周 | 1 份 = ¼ 杯 ≈ 30 g |
| 快餐 | < 1 次/周 | 含快餐类食物的餐次 |
| 酒精 | > 0 且 < 2 杯/天（男）/ < 1 杯/天（女） | 1 杯 = 14 g 纯酒精 |

每天 / 每周份数 = 统计期总量 ÷ 有记录的天数（× 7）。LE8 卡片里可以点“查看 16 题”看到每题的推算值。

## 5. 防癌建议：2018 WCRF/AICR 标准化评分（0–6）

世界癌症研究基金会与美国癌症研究所的 10 条防癌建议中，有 7 条可以按 Shams-White 等 2019 年发表的标准化方法评分，每条 1 分、等权：

| 建议 | 计分 |
|---|---|
| 保持健康体重 | BMI 18.5–24.9 得 0.5，25–29.9 得 0.25；腰围 男 < 94 cm / 女 < 80 cm 得 0.5，男 94–101.9 / 女 80–87.9 得 0.25（只有其中一项数据时该项分数加倍） |
| 积极运动 | 中高强度活动 ≥ 150 分钟/周得 1，75–149 得 0.5（按实际分钟，不做高强度加倍） |
| 多吃全谷物、蔬菜、水果、豆类 | 果蔬 ≥ 400 g/天得 0.5（200–399 得 0.25）；膳食纤维 ≥ 30 g/天得 0.5（15–29 得 0.25） |
| 少吃快餐和高脂高糖高淀粉的加工食品 | **不计分**（见第 8 节），只显示超加工食品供能比 |
| 限制红肉和加工肉 | 红肉 ≤ 500 g/周且加工肉 < 21 g/周得 1；加工肉 21–99 g/周得 0.5；红肉 > 500 g 或加工肉 ≥ 100 g/周得 0 |
| 限制含糖饮料 | 0 得 1；≤ 250 ml/天得 0.5；> 250 ml 得 0 |
| 限制饮酒 | 不饮酒得 1；≤ 28 g/天（男）/ 14 g/天（女）纯酒精得 0.5；更多得 0 |

母乳喂养一条是可选项，本系统不计。饮食相关各项需要统计期内 ≥ 3 天饮食记录。

## 6. 周期评分（周 / 月 / 任意区间）

```
周期总分 = 该周期的 Life's Essential 8（0–100）
```

周报 / 月报同时给出：

- **HEI-2020（按周期总摄入）**：把整个周期的摄入加在一起算一次 HEI，比单日更稳定；以及 **HEI 日均**；
- **MAR 日均**；
- **WCRF/AICR** 防癌评分；
- 以下只标状态、不加权的周期检查（目标按区间天数 ÷ 7 缩放）：

| 项目 | 目标 | 依据 |
|---|---|---|
| 红肉总量 | ≤ 500 g/周（理想 ≤ 350 g） | WCRF/AICR |
| 加工肉总量 | 越少越好 | WCRF/AICR、IARC |
| 海产品 | ≥ 8 盎司（约 227 g）/周 | DGA、FDA/EPA |
| 饮酒量 | 低于 NIAAA 大量饮酒阈值（男 15 杯 / 女 8 杯每周）；孕期等为 0 | NIAAA、DGA |
| 中高强度运动 | ≥ 150 分钟/周（理想 300），高强度按 2 倍计 | 体力活动指南 |
| 力量训练 | ≥ 2 天/周 | 体力活动指南 |
| 日均步数 | 参考 ≥ 7000 步（非官方标准，仅供参考） | — |
| 记录天数 | ≥ 6 天/周 | — |
| 体重变化速度（有减重/增重目标且 ≥ 7 天数据） | 减重每周 −0.2 至 −1.0 kg；增重 +0.1 至 +0.5 kg | CDC |

另外统计每个检查项在多少天达标，以及各类风险物出现的天数和累计剂量。

## 7. 能量与体重

```
当日消耗 TDEE：
  有手机/手表“活动能量”： (静息能量 + 活动能量 + 未被设备记录的运动) ÷ 0.9
  只有步数：            (静息 + 步数估算 + 运动) ÷ 0.9          步数估算 = 步数 × 身高 × 0.414 × 0.5 kcal/kg/km × 体重
  只有手动记录的运动：    “久坐”EER + 运动净消耗
  什么都没有：           档案活动水平对应的 EER
  （静息能量优先用设备值，否则用 BMR；÷ 0.9 表示食物热效应约占 10%）

今日目标 = TDEE + 目标调整（不低于能量下限）
运动净消耗 = (MET − 1) × 体重 kg × 小时        （扣除静息部分，避免和基础代谢重复）
```

- 运动（例如“游泳 5km”）由 AI 按 2024 Compendium 选择活动类型和 MET，并在没有给出时间时按常见速度推算时长；千卡数一律由服务器按上式计算。运动可以标记“已含在设备活动能量中”，避免重复计算。
- 趋势体重 = 每日称重的指数移动平均（α = 0.1），过滤水分、盐分造成的日间波动。
- 预测变化 = 累计（摄入 − 消耗）÷ 7700 kcal/kg。
- 反推日消耗 = 日均摄入 − 趋势体重变化 × 7700 ÷ 天数（需要 ≥ 14 天，且 ≥ 70% 的天记录完整）。它与公式估算的消耗差距越大，说明记录遗漏或设备估算偏差越大。

能量平衡本身只标状态；体重的结果体现在 LE8 的 BMI 与 WCRF 的健康体重两项中。

## 8. 局限与取舍

如实说明本系统在套用这些评分体系时做的取舍：

1. **WCRF“超加工食品”一条不计分。** 原文按研究人群内的三分位数评分（与同一人群比较），没有公开的绝对切点，无法用于单个用户，所以 WCRF 满分按 6 分显示。
2. **MEPA 的酒精题**按问卷原文“适量饮酒得 1 分”计分，这与 IARC“酒精没有安全剂量”的结论相反。WCRF 评分中以不饮酒为最佳，页面上也注明了这一点。
3. **LE8 的饮食分**官方有两种算法：人群研究用 HEI 百分位，个人用 MEPA 问卷。HEI 百分位切点需要全人群分布，没有可用于个人的公开表，所以用 MEPA，并由饮食记录自动推算而不是让用户答题。
4. **LE8 的扣分项**（服药 −20、二手烟 −20）扣到 0 为止。
5. **MAR 按 RDA 计算**：IOM 指出用 RDA 判断个人单日摄入是否充足只是粗略参考（RDA 覆盖 97.5% 的人群需要），所以 MAR 只作附加分，不作每日总分。
6. **单日 HEI 波动大**：HEI 设计用于较长时间的饮食评估，请更多参考 7 日均线和周报中的周期 HEI。
7. **IARC 风险物不计分**，原因见 3.4。
8. **营养数据来自 AI 估算**（品牌食品会联网查询营养成分表），误差会传递到所有分数。合并前请在预览里核对和修改份量。

---

## 9. 记录完整度

当天摄入低于 BMR 的 60%，或者少于 2 餐时，标记“记录可能不完整”，但仍然给出评分。几乎不含能量的记录（只喝水、黑咖啡）不算作一餐。

## 10. 修改规则

所有阈值都在代码里集中定义，修改后提高 `SCORING_VERSION`（`server/src/scoring/daily.ts`），缓存的历史评分会自动重算：

- 人群 DRI：`server/src/standards/dri.ts`
- 个性化目标与限量：`server/src/standards/targets.ts`
- HEI-2020：`server/src/standards/hei.ts`
- 风险物：`server/src/standards/hazards.ts`
- 运动 MET：`server/src/standards/met.ts`
- 每日评分与 MAR：`server/src/scoring/daily.ts`
- LE8、MEPA、WCRF/AICR：`server/src/scoring/le8.ts`、`mepa.ts`、`wcrf.ts`、`indices.ts`
- 周期评分：`server/src/scoring/period.ts`

> 评分用于自我管理参考，不构成医疗建议。孕期、慢性病（尤其肾病、糖尿病）请遵医嘱调整目标。
